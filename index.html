Pertanyaan yang Sering Muncul.

Apakah saya butuh keahlian IT untuk memakai ini? +
Tidak sama sekali (terutama jika Anda memilih Paket Terima Beres). Anda hanya butuh aplikasi Telegram untuk mencatat transaksi sehari-hari, sama seperti membalas chat pelanggan.
Apakah bisa tracking status operasional / resi? +
Sistem utama ini fokus mengamankan Arus Kas (Pemasukan, Pengeluaran, Laba Rugi) Anda terlebih dahulu. Untuk sistem operasional khusus (seperti tracking rak, cetak resi thermal otomatis), tersedia paket Custom Build mulai dari Rp 1,5 Juta. Silakan hubungi kami untuk detailnya.
Bagaimana jika saya mencampur uang pribadi dan usaha? +
Tidak masalah! Cukup sebutkan saat chat (misal: "Ambil uang laci 50rb buat jajan"). Admin Virtual akan mencatatnya di kolom khusus "Pribadi" sehingga laporan laba/rugi bersih usaha Anda tidak akan rusak atau tercampur.
Apakah ada biaya bulanan (langganan)? +
Kabar baiknya: TIDAK ADA! Jika Anda mengambil Paket Terima Beres, Anda sudah mendapatkan GRATIS biaya operasional Server Cloud dan Token selama 1 Tahun Penuh. Anda baru akan membayar perpanjangan server di tahun ke-2, itu pun biayanya sangat murah (hanya sekitar Rp 199.000 per TAHUN, atau setara 16 ribuan per bulan). Sangat ramah untuk kas UMKM.
Apakah ada batasan jumlah chat per harinya? +
Untuk menjaga agar sistem tetap cepat dan tidak error, Paket Terima Beres sudah mencakup Gratis Kuota hingga 1.500 chat transaksi per bulan (sekitar 50 nota transaksi setiap hari).

Bagi 90% UMKM, kuota ini sangat berlebih. Namun, jika bisnis Anda sedang sangat ramai dan melebihi kuota tersebut, jangan khawatir! Biaya isi ulang (top-up) kuota tambahan sangatlah murah, hanya sekitar Rp 25.000 untuk ribuan transaksi berikutnya.
